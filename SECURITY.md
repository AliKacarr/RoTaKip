# Security Policy

## Supported Versions

The following versions of RoTaKip are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ |
| Older versions | ❌ |

Only the latest version available on the `main` branch receives security updates and fixes.

---

## Reporting a Vulnerability

If you discover a security vulnerability in RoTaKip, please report it responsibly.

### How to Report

alikacardev@gmail.com

Please open a private security report by contacting the maintainer through:

- GitHub Issues (for non-sensitive reports)
- GitHub Security Advisories (preferred for sensitive vulnerabilities)

Do **not** publicly disclose the vulnerability until it has been reviewed and fixed.

### What to Include

Please include as much information as possible:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Screenshots or proof-of-concept (if available)
- Suggested fix (optional)

### Response Timeline

You can generally expect:

- Initial response within **3–7 days**
- Status updates during investigation
- A fix or mitigation if the vulnerability is confirmed

Valid security reports will be investigated and addressed as soon as possible.

Thank you for helping improve the security of RoTaKip.
